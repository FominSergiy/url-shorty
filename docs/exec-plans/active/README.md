# Active Execution Plans

Each file here is one initiative in flight.

Filename format: `<YYYY-MM-DD>-<short-name>.md`

When an initiative completes, move its file to `../completed/`.

## Template

```markdown
# <Initiative name>

**Status**: In progress  
**Assigned to**: Worker agent  
**GitHub issue**: #<N>  
**Started**: YYYY-MM-DD

## Goal
[One sentence]

## Steps
- [ ] Step 1
- [ ] Step 2

## Done when
[Acceptance criteria]
```
